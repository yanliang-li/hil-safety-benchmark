# 文献与六指标修订记录

使用 nature-writing 的论点—证据—边界组织方式，并按用户要求写简单句。目标仍是 ICLR 研究初稿，不套用 Nature 的文章格式或期刊用语。论文采用“合法工作流中的间接攻击，是否通过正确询问与反馈使用获得有用且安全的结果”这一主论点。

## 论点、证据与边界

| 论点 | 可用证据 | 表达边界 |
|---|---|---|
| 问人和安全执行是不同能力 | neutral 的 16 次未问攻击、2 次问后攻击、2 次批准遗漏 | 不能用未执行推断理解或识别 |
| 当前提示策略值得保留 | 同清单 80+80；ASR 18→8；BCR 76→76 | 一个配置、开发 pilot、非同期随机对照 |
| 六维比单一安全分更能揭示问题 | 严格回复后 22/26→21/27；共同询问 19/23→21/23 | 分母改变；不能写全面提升或因果效果 |
| 本文连接间接攻击与回复后的权限控制 | AgentDojo/SkillHarm 与 HiL/HAS/HumanAgency 的原文 | HAS 已有批准安全；不声称首次研究人类授权 |
| 原始冗余工作机制仍重要 | retail 原始材料、invoice 衍生轨迹及两组残余失败 | 原始 Claude 成功日志缺失，不伪造恢复 |
| 六指标中的识别与问题质量需要语义审查 | 当前规则及新增标注规范 | ARIR 留空；100% 问题匹配是代理 |

## 段落分工

摘要：问题 → benchmark → 四回复与六维 → 已完成对照 → 负面结果与边界。

引言：冗余验证案例 → 两类文献连接 → 回复不能自动创造权限 → benchmark 任务与条件 → 指标为什么分组 → 当前贡献和证据。

相关工作：工具行为和注入 → 人类协作及授权 → 提示与执行层防御。每段承认已有工作，再说明本文聚焦的问题。

防御：主文写真实测试的权限提示及两个残余机制；SAIL 的授权账本、作用域、完整派发检查移到附录，保留未来设计。

## 术语表

| 术语 | 固定含义 |
|---|---|
| task / case | 基础任务 / 一个任务的一种回复条件 |
| framework / model / configuration | 执行框架 / 后端模型 / 两者及推理设置的组合 |
| attacker-targeted effect / unsafe outcome | 攻击者想触发的效果 / 未获有效授权的效果 |
| confirmable / prohibited | 可经有效授权允许 / 普通人类批准不能解除 |
| response accuracy / strict post-feedback success | 仅行动符合回复 / 还要求良性任务完成且安全 |
| recognition / source exposure | 可见证据支持正确识别 / 只确认读到了载体 |
| independent starts / shared prefix | 同初始环境独立跑 / 同模型上下文和工具状态恢复；后者未实现 |
| prompt guard / runtime guard | 已测试的提示条件 / 尚未实现的执行前检查 |

## 正文取舍

摘要、引言和 related work 已重写，避免大段背景和功能宣称。六指标成为主表，旧七指标表移到附录。旧 benchmark 勾选矩阵改为有来源的设置对比。保留拟议风险 taxonomy 的明确标签，不把它当代码覆盖统计。

空白分隔计数（含 LaTeX 命令，非期刊正式 word count）见 build/writing_audit_counts.json。主文截至第九页；新文献和拟议 SAIL 细节增加附录长度，不通过压字号或改版心挤页数。

仍缺：独立任务/语义标注、错误与部分授权任务、共享状态分叉、未见测试集、多配置运行、有/无 HIL 对照。它们作为明确后续工作，不因写入论文而视为已完成。
