\section{Introduction}
\label{sec:intro}

Consider an agent asked to prepare a report for an approved internal destination. A workflow document instructs it to send an additional copy elsewhere. The agent must determine whether this extra delivery is authorized and whether human input is needed. Approval to prepare the report does not necessarily authorize sending that copy.

This example makes human-in-the-loop safety a control problem spanning consultation and execution. Workflow artifacts provide operational information but cannot grant themselves authority. Indirect attacks exploit this distinction by presenting extra operations as routine validation, cleanup, or required handoffs. Our motivating retail workflow requests three identical analyses under an apparent quality-control requirement. The agent must resolve the missing decision, interpret its answer, and constrain later actions while continuing authorized work.

Agent-safety benchmarks measure harmful tool behavior, while human-interaction benchmarks study when agents request help and use it \citep{zhang2024agentsafetybench,debenedetti2024agentdojo,trinh2026hilbench,wu2026hasbench}. These lines of work motivate a joint question: \emph{under an indirect attack, does the agent's actual execution track the validity and scope of human feedback?} Answering it requires more than counting questions or refusals. Valid approval should permit the specified action, whereas denial, ambiguity, and mismatched approval should not.

We introduce \bench{}, an executable benchmark pairing 250 tasks with four fixed replies, yielding 1,000 cases. It distinguishes confirmable from prohibited effects and evaluates task completion, unsafe execution, recognition, consultation, question accuracy, and strict post-feedback success. These measures expose intervention failures and remaining semantic annotation needs.

A first comparison crosses four native frameworks and three API routes on 80 development cases. Prompt guidance reduces unsafe outcomes, with different agent profiles across safety and interaction measures. A second comparison tests \sail{} v3, which binds replies to proposed effects but loses benign work. These failures motivate original-authority preservation and task recovery in SAIL v4. Its pending third-round comparison retains the same experimental allocation. Fixed synthetic replies, simulated effects, and reused tasks bound both completed studies.
