\section{Related Work}
\label{sec:related}

\paragraph{Benchmarks and human feedback.}
Several benchmarks study safety risks in tool-using agents. Examples include
ToolEmu, R-Judge, AgentDojo, and Agent-SafetyBench
\citep{ruan2024toolemu,yuan2024rjudge,debenedetti2024agentdojo,zhang2024agentsafetybench}.
Other benchmarks focus on multi-turn interactions, malicious skills, or actions
that go beyond the user's request
\citep{li2026unsafer,ning2026skillharm,jin2026skillsafetybench,qu2026overeager}.
HiL-Bench asks when an agent should seek human help \citep{trinh2026hilbench}.
HAS-Bench and HumanAgencyBench examine human feedback and user control
\citep{wu2026hasbench,sturgeon2025humanagencybench}.
\bench{} studies the full process around a human reply. Each trace records the
agent's question, the scope of the reply, and the actions that follow. The
benchmark reports two outcomes separately. One is whether the agent follows the
reply. The other is whether it completes an optional action that the user
approved. Appendix~\ref{app:comparison} provides a detailed comparison with
prior benchmarks.

\paragraph{Runtime defenses.}
Content guards detect harmful text
\citep{inan2023llamaguard,han2024wildguard,zeng2024shieldgemma}.
StruQ and SecAlign distinguish trusted instructions from untrusted content
\citep{chen2025struq,chen2025secalign}.
GuardAgent, CaMeL, and ToolSafe check actions during execution
\citep{xiang2025guardagent,debenedetti2025camel,toolsafe2026}.
Progent limits tool privileges. It asks for approval before granting new
permissions. SafeAgent tracks state during execution and supports recovery
\citep{shi2025progent,liu2026safeagent}.
However, adaptive attacks can still bypass defenses against indirect prompt
injection \citep{zhan2025adaptive}.
\sail{}-HIL uses the human reply as permission for one specific action. The
permission can be used only once. If the reply is unclear, the system asks a
limited number of follow-up questions. It can also block unsafe actions and
help the agent continue the original task.
