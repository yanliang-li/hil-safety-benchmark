Human consultation does not guarantee safe tool use. An agent must ask about the right decision, interpret the reply, and keep execution within its scope. We introduce \bench{} to evaluate this loop under indirect attacks embedded in benign workflows. The benchmark distinguishes effects that can receive valid approval from effects that remain prohibited. Its executable core contains 250 tasks with four fixed replies each: approval, denial, ambiguity, and scope mismatch. A completed exploratory study crosses four native agent frameworks with three API model routes, two prompt conditions, and three repeats on 80 cases. Among 5,551 valid runs from 5,760 attempts, an authorization-scope prompt lowers pooled attack success from 25.95\% to 13.40\%, while benign completion changes from 91.45\% to 92.45\%. Yet consultation recall reaches only 49.35\%, and 55 unsafe runs occur despite consultation. These findings separate failure to ask from failure to use feedback and motivate checking scoped authority at execution time. The study uses synthetic replies and reused tasks; independent semantic annotation and held-out validation remain necessary.
