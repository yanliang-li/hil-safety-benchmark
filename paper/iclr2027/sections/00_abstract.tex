Tool-using agents sometimes need human approval before taking sensitive
actions. Asking is not enough: an agent must understand what was approved,
avoid unapproved actions, and still complete the original task. We introduce
\bench{}, a benchmark for testing this full process. It contains 120 cases with
six stateful reply patterns, including approval, denial, ambiguity, and approval
for a related but different action. \bench{} records whether an
agent notices the risk, asks the right question, follows the reply, avoids unsafe
actions, and completes the task. We also introduce \sail{}-HIL, a runtime
controller that blocks actions without sufficient authority, asks for
clarification, and allows an approved action only once. A blinded audit by an
independent model matched the intended decision and scope on 191 of 200 reply turns
(95.5\%); all strict mismatches involved replies that approved a related but
different action. An ongoing
1,980-run evaluation compares \sail{}-HIL with prompt-based control and versions
without key components to test whether clarification reduces unsafe actions
without lowering task completion.
