# 四框架最终实验结果

汇总时间：2026-09-13 00:01:11 CST。

本轮共 5,760 次运行：4 个框架 × 3 个请求模型 × 80 个案例 × 3 次重复 × 2 个条件。5,551 次有效，209 次失败（3.63%），无待运行任务。80 个案例来自 20 个基础任务，每个任务有 4 种固定回复；重复运行不是新的独立任务。

条件为 neutral（未添加本轮提示防御）与 prompt_guard_v1（添加授权范围提示防御）。所有指标按冻结的评分规则计算。下表先给全体有效运行按计数合并的描述性比例，之后列出每个框架与模型；它们不是独立样本上的泛化性能估计。

## 总体结果

攻击成功率相对下降 48.37%。这是上述有效运行汇总比例的相对变化。

良性任务完成率评价攻击场景中的原始合法任务是否完成；它允许与攻击成功同时发生。“完成任务且未发生攻击”才同时要求任务成功与安全。

询问召回率以预设应当询问的有效案例为分母。回复后严格成功以实际询问过人的有效案例为分母，要求回复后动作正确、原任务完成且未发生攻击。两种条件询问了不同的案例子集，不能把条件比例的变化解释成人类回复本身的因果效果。

自主风险识别率与提问语义准确率尚无独立标签，当前为 N/A。提问规则匹配率按询问次数计算，不是语义准确率，也不证明询问覆盖了所有关键风险。

## 解读范围与文件来源

- 12 个框架与模型组合中，观测到的攻击成功率均下降；其他指标并非在每个组合都提升。
- 本轮是复用的 80 案例探索集，不是整个 1,000 案例核心集，也不是全新留出测试集。
- 模型名称是第三方 API 请求 ID，无法据此核验底层权重。Codex、Claude Code、Hermes 和 DeepSeek Harness 在这里是运行框架。
- Hermes 后加入、上下文设置为 65,536；Codex 与 DeepSeek Harness 为 32,768，Claude Code 使用原生处理。框架默认提示、运行时、运行时间段和服务行为均可能影响比较。
- 当前人类回复为固定合成回复，不是人类被试实验。
