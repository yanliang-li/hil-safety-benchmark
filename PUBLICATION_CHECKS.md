# Public release checks

This checkout was exported from an explicit file allowlist. It contains the executable benchmark, synthetic V4 cases, tests, selected research documentation, aggregate pilot results, and a self-contained manuscript source tree.

Personal conversation archives, API and SSH credentials, local authentication stores, recovery archives, and external paper PDFs were excluded. The export was checked for credential patterns and the supplied API key without printing the credential. No matches remained.

The manuscript's figures and tables are included. Historical raw model trajectories are not included in this initial export; some analysis utilities require those private local inputs. Existing aggregate results are labeled as exploratory.

The native three-framework API runner, frozen 4,320-attempt plan, compatibility records, and manuscript protocol appendix were added after local testing. New main-run counts are published only from event-replayed results, with provisional status while the matrix runs.
